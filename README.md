# HR Portal

A full-stack HR Portal designed to manage employees, attendance, leave requests, holidays, notifications, feedback, and user profiles.

## 🚀 Live Demo

👉 **Frontend:** https://hr-portal-pi-ten.vercel.app/login

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- React Router
- Tailwind CSS
- Axios
- Vite

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication
- REST APIs
- Nodemailer

## ✨ Features

- 🔐 User Authentication
- 👥 Employee Management
- 🕐 Attendance Management
- 📝 Leave Request & Approval
- 📅 Holiday Calendar
- 🔔 Notifications
- 💬 Employee Feedback
- 👤 Profile Management
- 📧 Email Notifications
- 📱 Responsive UI
